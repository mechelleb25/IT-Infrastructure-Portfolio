# Smart Refrigerator Monitoring System

**Electrical and Computer Engineering capstone | CEE498 / CEE499A**

**Status:** In progress. This page records confirmed responsibilities and procurement, not a claim of a completed prototype.

## Purpose
Design a refrigerator-monitoring prototype for restaurant refrigeration using temperature and humidity sensing, a local display, and Wi-Fi connectivity/alerts.

## Planned architecture
- ESP32 / ESP-WROOM-32 development board
- DHT22 / AM2302 humidity sensor
- DS18B20 temperature sensor
- OLED display
- Wi-Fi connectivity and alerts

## Team responsibilities
